# 给 AI 助手的本机启动指南

用户说“帮我把项目跑起来”时，由你把这个项目目录里的 OpenERP 打开，直到用户能在浏览器里看到应用。首次使用时由用户在页面上设置管理员密码。

先确认当前目录是否已有可复用的实例。若用户提到正在使用的业务站点，且操作对象有歧义，先问清楚要打开哪一份。

按[环境准备](../development.md#环境准备)检查本机工具。当前 AppHost 需要能运行 Linux 容器的环境。遇到“找不到命令”时，核对工具的安装位置与当前会话的 PATH；遇到“拒绝访问”时，核对服务状态与当前会话的权限。在已有权限内处理并重试。确需安装系统软件或更改电脑设置时，用日常用语说明具体会改什么、对这台电脑有什么影响，请用户决定是否继续。

依照仓库的 [Aspire 指引](../../.agents/skills/aspire/SKILL.md)和[启动与停止](../development.md#启动与停止)启动项目。等 API 和 Web 就绪，检查 Web 地址能否正常显示 OpenERP 的登录页、首次设置页或已登录的应用页面。如果浏览器显示证书警告，继续排查本机信任设置。只能检查到部分结果时，告诉用户已经验证了什么、具体卡在哪里。

页面可用后，把可直接打开的 Web 地址交给用户。用户再次请求打开时，复用属于该项目目录的实例和数据。

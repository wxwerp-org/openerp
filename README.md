# OpenERP

OpenERP 帮助你查看私有 ERP 中的店铺与平台授权状态，通过平台接口将历史订单同步到本地，并按店铺核对订单数和商品件数。

## 快速开始

1. 打开已部署的 OpenERP 站点。首次部署的管理员请在开放访问前按页面提示设置密码，再用 `admin` 登录。自行部署见[部署说明](docs/deployment.md)。
2. 管理员打开右上角账户菜单，进入「系统设置」直达「ERP 接入」，保存[私有 ERP](https://v3-api.wxwerp.com) 的 Open API Token。
3. 管理员或员工进入「店铺 → 授权店铺」，点击「授权新店」前往旺销王办理。授权完成后，等待定时目录同步，或由管理员点击「立即同步」。管理员在「设置 → 用户管理」将同步到的店铺分配给负责人。
4. 打开「订单管理 → 订单同步」，列表里是「授权店铺」中的全部店铺，不需要再单独添加或配置平台凭据。点击店铺的「同步订单」，或点击「全部同步」并行同步自己可见的店铺。尚未实现订单同步的平台会列出，但不能同步，「全部同步」会忽略它们。完成后可在「订单列表」直接用平台订单号查单。

订单同步通过旺销王的平台接口按店铺编号读取平台订单，使用「ERP 接入」里保存的 Token。更换 Token 后，下一轮授权店铺同步或下一家店的订单同步会使用新凭证。已经开始读取的店铺目录或单店订单会继续使用开始时的凭证。

## 功能

- **授权店铺**。从私有 ERP 同步店铺目录与平台授权状态到本地；员工可按平台和关键词查找负责的店铺、查看授权状态或失败原因，并前往旺销王续授权。管理员还可按授权状态筛选全部店铺。旺销王暂时离线时仍可查询本地目录。
- **订单同步**。通过旺销王的平台接口同步订单，目前支持 AliExpress，店铺来自「授权店铺」。在「订单管理 → 订单同步」页查看实时进度和新增、更新、跳过数，管理员还可选择店铺启用定时同步，默认每 30 分钟一次。手动或定时同步写入订单后，列表会按当前筛选刷新。
- **订单列表**。支持按平台订单号或号码片段查单，也可按店铺、平台、订单状态和创建日期筛选。同一张订单关联的平台订单号在一行展示，各自列出平台状态。平台暂时不可用时仍可查看已同步订单。
- **员工账号**。管理员在「设置 → 用户管理」添加、查看、编辑和删除员工账号。新员工从零家店开始。每名员工可负责多家店，同一家店也可分配给多名员工。分配后即可查历史订单和同步订单。撤销分配后失去该店的历史数据访问权。员工可编辑本人资料和修改密码。改名后旧用户名立即可用，删除账号后其用户名保留 7 天。
- **文件存储**。提供文件上传和下载 API。

# OpenERP

OpenERP 帮助你查看私有 ERP 中的店铺与平台授权状态，将历史订单同步到本地，并按店铺核对订单数和商品件数。

## 快速开始

1. 打开已部署的 OpenERP 站点。首次部署的管理员请在开放访问前按页面提示设置密码，再用 `admin` 登录。自行部署见[部署说明](docs/deployment.md)。
2. 管理员打开右上角账户菜单，进入「系统设置」直达「ERP 接入」，保存[私有 ERP](https://v3-api.wxwerp.com) 的 Open API Token。
3. 管理员进入「店铺 → 授权店铺」查看店铺状态，点击「立即同步」刷新目录。需要重新授权时，管理员可从店铺列表或详情点击「去 wxw 授权」，完成后回到本页同步。
4. 打开「订单列表」，点击工具栏的「同步历史订单」，可单独同步一家店铺，也可点击「全部同步」并行同步本地目录中所有 TemuPop 店铺。完成后可直接用平台订单号查单，或打开「订单管理 → 商品量报表」核对汇总。

更换 ERP Token 后，下一轮授权店铺同步或下一家店的订单同步会使用新凭证。已经开始读取的店铺目录或单店订单会继续使用开始时的凭证。

## 功能

- **工作台**。首页展示本地订单概览、平台分布与店铺商品量排行，全部数字来自本地已同步数据并标注查询时间。空库时管理员会看到四步初始化引导（配置 ERP → 上游授权 → 同步目录 → 同步订单），同步进度与失败原因直接显示在页面上；数据可下钻到商品量报表。
- **授权店铺**。从私有 ERP 同步店铺目录与平台授权状态到本地；页面支持平台/授权状态/关键词筛选、分页、详情与 wxw 授权深链，wxw 暂时离线时仍可查询。
- **订单同步**。在订单列表的同步面板查看实时进度和新增、更新、跳过数，管理员还可选择店铺启用定时同步，默认每 30 分钟一次。手动或定时同步写入订单后，列表会按当前筛选刷新。
- **订单列表**。支持按平台订单号或号码片段查单，也可按店铺、平台、订单状态和创建日期筛选。同一张 ERP 订单关联的平台订单号在一行展示，各自列出平台状态。ERP 暂时离线时仍可查看已同步订单。
- **商品量报表**。按平台和店铺汇总已同步的订单，展开明细核对商品件数。件数取自订单快照，统计时不另扣取消或退款数量。详见[报表数量口径](docs/order-snapshot-report.md#数量口径)。
- **员工账号**。管理员在「设置 → 用户管理」添加、查看、编辑和删除员工账号。员工可使用自己的账号查单、发起同步、编辑本人资料和修改密码。改名后旧用户名立即可用，删除账号后其用户名保留 7 天。
- **文件存储**。提供文件上传和下载 API。
